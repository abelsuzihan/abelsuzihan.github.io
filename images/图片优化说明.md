# 图片优化说明

这个网站使用“原图 + 可选的 preview + 可选的 WebP”方案。

## 第一次使用

需要先安装 Node.js 的 LTS 版本：

<https://nodejs.org/>

安装后打开 Mac 的“终端”，依次运行：

```bash
cd "/Users/suzihan/Documents/GitHub/absu12.github.io"
npm install
npm run images
```

`npm install` 只需要第一次运行。它会安装图片处理工具。`npm run images` 才是每次真正执行图片批处理的命令。

网页代码会从 `image-manifest.json` 读取图片尺寸和辅助资源信息。批处理脚本还会自动扫描 HTML，并补齐或更新对应图片的 `width` / `height`，所以以后新增图片不需要手动计算和填写尺寸。

## 以后新增或替换图片

只需要把新的 JPG、JPEG 或 PNG 原图放入 `images/`，并在文章 HTML 中添加：

```html
<img data-image-original="../images/new-picture.jpg" alt="图片说明">
```

然后运行：

```bash
cd "/Users/suzihan/Documents/GitHub/absu12.github.io"
npm run images
```

脚本不会修改原图，会根据每张原图生成：

```text
原图.jpg
原图.preview.jpg
原图.webp
```

PNG 会生成：

```text
原图.png
原图.preview.png
原图.webp
```

WebP 与原图保持相同像素尺寸；preview 只生成一张较小的占位图。PNG 的 WebP 使用无损模式，以尽量保护透明度和界面细节。

## 忽略某些图片

如果某张图片本来就很小，或者不希望为它生成辅助资源，可以编辑：

```text
images/image-ignore.txt
```

每行写一个相对于网站根目录的路径，例如：

```text
images/favicon.png
images/blank.png
```

然后再次运行：

```bash
npm run images
```

脚本会删除之前由脚本生成的对应 preview 和 WebP，但不会删除原图。

GIF、SVG 和其他格式不会被这个脚本处理，也不会被删除。

## 删除或改名图片

删除或改名原图后，再运行一次：

```bash
npm run images
```

脚本会根据之前的图片清单清理旧的 preview 和 WebP，并重新生成当前仍存在的资源。之后检查 Git 变更，确认无误后再提交。

## 上传 GitHub

确认网站和生成的图片没有问题后，使用原来的 Git 流程：

```bash
git status
git add .
git commit -m "Update image assets"
git push origin main
```

建议先运行 `git status`，确认没有不想上传的文件。

## 缺少辅助图片时会怎样

网站代码已经做了兼容：

- 没有 preview：直接显示 WebP 或原图。
- 没有 WebP：直接显示原 JPG、JPEG 或 PNG。
- 两种辅助图片都没有：原图仍然正常显示。
- 浏览器不支持 WebP：自动使用原图作为 fallback。

因此不需要一次性为所有文章图片生成辅助资源。

如果以后手动在文章 HTML 中增加图片，请使用下面这种写法，把原图写在 `data-image-original` 中：

```html
<img data-image-original="../images/new-picture.jpg" alt="图片说明">
```

不要把 `.preview.jpg` 或 `.webp` 写成唯一图片地址，也不需要手动添加 `width` / `height`。运行 `npm run images` 后，脚本会自动更新 HTML 尺寸；网页会根据 `image-manifest.json` 自动决定是否使用辅助资源。如果辅助资源不存在，仍会显示 `data-image-original` 指向的原图。

## 注意事项

- 不要把 `.preview.*` 文件当作原图继续编辑。
- 原图文件名尽量使用英文、数字、短横线或下划线。
- 处理完成后，`image-manifest.json` 也需要一起提交，因为网页会用它判断哪些辅助资源存在以及读取图片尺寸。
- 这个脚本只处理 `images/` 目录下的 JPG、JPEG 和 PNG，不会处理 GIF。
